#### IEP Form Sections
1. Page header — title, student name/LRN, school year badge, status badge, Print IEP button
2. Learner Information — auto-fill from `student_records` (all editable)
3. Core IEP Fields — Developmental Domain (dropdown from PDSP domains, fallback to 6 DepEd standard domains), Priority Needs, Terminal Objectives, Re-evaluation Date
4. Steps Table (left 60%) + PDSP/Assessment Docs Panel (right 40%, collapsible)
5. Signing Method — Print & Upload vs Digital Signatures cards
6. Signatories — **method-aware**:
   - Digital + signing: status display (green check = signed, gray = pending, Sign button for current user's slot)
   - Print & Upload: name inputs + F2F checkbox per slot
   - No method: name inputs only
7. SPED Teacher Signature Pad — separate card, saves immediately via AJAX
8. Send IEP Draft — sends to Parent + Guidance + Principal (in-system + email)
9. Action Bar — Save Draft (navy) + Mark as Signed (crimson) side by side

#### Signing Flow
**Digital:**
1. SPED Teacher fills form → selects Digital → saves draft
2. Clicks Send IEP Draft → validation → confirmation → sends to Parent/Guidance/Principal
3. Status → `signing`, `iep_copies` records created, notifications sent
4. Each recipient opens `/iep/form/{id}` → sees their Sign button → goes to `/iep/sign/{id}/{sigId}`
5. Signs with canvas pad → PNG saved to `/uploads/signatures/iep/`
6. Signature reflects on SPED Teacher's view
7. SPED Teacher signs their own pad
8. Mark as Signed → validates → locks IEP → notifies all parties

**Print & Upload:**
1. SPED Teacher fills form → selects Print & Upload → saves draft
2. Clicks Print IEP → browser print dialog → clean DepEd layout
3. Signs physically → uploads signed document
4. Checks F2F checkbox per signatory who signed on paper
5. Mark as Signed → locks IEP

#### Security Fixes Applied
- `signPage()` — role verification: guidance→guidance_counselor, principal→school_head, parent→parent_guardian. Wrong role = blocked
- `saveSignature()` — same role verification + IEP status check
- `sendDraft()` — validation: signatories required, re-eval date required, status must be draft/signing
- `markSigned()` — IEP must be in `signing` state (must send draft first)
- `permissions.php` — removed `iep.create` from guidance and principal (only SPED Teacher creates IEPs)

#### IEP Locking Rules
- Status: `draft` → `signing` (on Send Draft) → `signed` (on Mark as Signed) → `locked`
- Once signed: all fields read-only, no edits
- Re-evaluation date passed → crimson banner shown
- New Cycle: old IEP preserved as version, new draft created
